# UI Lab 반응형 워크스페이스

## 목적

실험 목록을 찾는 화면과 결과를 비교하는 화면에 같은 탐색 체계를 제공합니다.
데스크톱에서는 사용 가능한 폭을 충분히 쓰고, 태블릿과 모바일에서는 메뉴와 비교 대상을 전환해 읽을 수 있도록 설계했습니다.
디자인 적용 대상은 관리·비교 허브인 `apps/lab-shell`입니다.

## 화면 구조

- 실험실 개요: 실행 가능한 실험, 코드 비교 미리보기, 저장된 SSR 측정 요약, 카테고리 필터.
- SSR · 성능 분석: 실제 저장된 content-ready 지표와 조건, 응답 상세표, 별도 Lighthouse 기록.
- React / Next.js 기능: 버전별 카탈로그와 실행 결과·소스 코드 비교.
- UI 패턴: 페이지 이동과 무한 스크롤 데모, 훅·어댑터 코드 해설.
- 검증 리포트: 리포트 목록, 판정 필터, 상세 설명.

## 반응형 규칙

| 뷰포트      | 탐색 메뉴                                      | 결과·코드 비교      | 일반 콘텐츠                            |
| ----------- | ---------------------------------------------- | ------------------- | -------------------------------------- |
| 1280px 이상 | 232px 고정 사이드바, 버튼으로 72px까지 접기    | A/B 좌우 배치       | 화면 폭을 모두 사용, 카탈로그 최대 3열 |
| 1024–1279px | 72px 아이콘 레일, 메뉴 버튼으로 전체 목록 열기 | A/B 좌우 배치       | 카탈로그 2열 중심                      |
| 768–1023px  | 72px 아이콘 레일, 메뉴 버튼으로 전체 목록 열기 | A/B 전환            | 카드 2열, 상세 영역 세로 배치          |
| 767px 이하  | 상단 메뉴 버튼과 모달 내비게이션               | A/B 전환, 상태 유지 | 카드 1열, 표·코드는 패널 안에서 스크롤 |

공통 상단 바 높이는 64px입니다. 비교 화면은 상단 바를 제외한 높이를 사용합니다.
폭 전체에 `max-width`를 적용하지 않고, 설명 문단에만 필요한 읽기 폭을 제한합니다.
태블릿과 모바일에서도 레이블이 있는 전체 메뉴를 열 수 있습니다.

## 시각 규칙

| 역할                  | 값                                                |
| --------------------- | ------------------------------------------------- |
| 바탕                  | `#f7f8fa`                                         |
| 사이드 메뉴 / 보조 면 | `#f5f7f8`                                         |
| 카드                  | 흰색, 1px `#e4e8eb` 테두리                        |
| 본문                  | `#182329`                                         |
| 보조 본문             | `#5f6d77`                                         |
| 작은 레이블           | `#64737c`                                         |
| 주요 동작 / 선택      | `#087f72`                                         |
| 선택 배경             | `#e7f3ef`                                         |
| 코드 미리보기         | 차콜 계열 배경, A 앰버 / B 틸 강조                |
| 서체                  | 설치된 Pretendard, 코드와 수치는 시스템 monospace |

기본 카드 모서리는 12px, 작은 컨트롤은 8px입니다.
외부 Google Fonts 요청 없이 기존 Pretendard 패키지를 사용합니다.
시각 효과보다 코드의 폭, 수치의 정렬, 메뉴의 활성 상태를 우선합니다.

## 동작과 접근성

- 전역 검색: 검색 버튼 또는 `Cmd/Ctrl + K`, `Escape`로 닫기.
- 검색과 모바일 메뉴: native dialog의 모달 포커스 제어, 명확한 접근성 이름.
- 키보드 사용자를 위한 본문 바로 가기와 포커스 표시.
- 현재 메뉴는 `aria-current`, 필터·비교 모드는 선택 상태를 전달합니다.
- 비교 포인트는 hover뿐 아니라 클릭과 키보드로 선택할 수 있습니다.
- A/B 전환과 실행 결과·코드 전환 시 데모 상태를 보존합니다.
- 코드의 가로·세로 스크롤과 관련 줄 이동은 해당 패널 내부에서 처리합니다.
- 모션 감소 설정을 존중합니다.

## 측정값 표시 원칙

성능 화면은 `perf-results/ssr/latest.json`과 `perf-results/lighthouse/latest.json`을 읽습니다.
정적 import로 배포 번들에 포함하므로 별도의 파일 읽기 권한이나 추가 서버 요청이 필요하지 않습니다.
현재 저장된 SSR 기록은 2026-05-31의 **1회 quick 실행**입니다. 측정 날짜·횟수·환경을 함께 표시하고, 20회 반복 측정 리포트로 연결합니다.
Streaming/Blocking 방식을 구분하고, content-ready를 우선 표시하며 TTFB와 혼동하지 않도록 설명합니다.
이 디자인 작업은 새로운 벤치마크 실행이나 성능 개선 측정을 수행한 작업이 아닙니다.

## 검증 범위

- 전체 워크스페이스 `yarn lint`, `yarn build`.
- Home: 320, 390, 834, 1440, 1920px에서 문서 가로 넘침 확인.
- 기능 비교 3개와 훅·어댑터 해설: 390, 834, 1440px에서 렌더링과 가로 넘침 확인.
- SSR·리포트: 390, 834, 1440px에서 표 내부 스크롤, 목록 열기, 리포트 필터 확인.
- 메뉴 접기, 검색 열기·닫기·이동, 카테고리 필터, A/B 상태 유지, 토픽과 코드 줄 대응 확인.
- 실제 UI 패턴 데모의 데이터 로드는 기존 DummyJSON API를 사용합니다. 최종 로컬 production 검증에서 기본 데모와 어댑터 데모 모두 HTTP 200 응답을 확인했고, 브라우저 `pageerror`는 0건이었습니다.
