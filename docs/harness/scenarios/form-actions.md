# Form Actions · 입력 복원

경로: `/front-feature/react/form-actions` · 미리보기: `#/features/react/form-actions`

같은 로컬 `saveProfile` 함수를 수동 `onSubmit`과 `useActionState`에 연결합니다. 800ms는 진행 상태를 관찰하기 위한 지연이며 서버 저장·성능 측정은 아닙니다.

- 오류: 제출 원문을 앞뒤 공백까지 보존합니다. 마지막 저장 이름은 바뀌지 않습니다.
- 성공: 앞뒤 공백을 뺀 이름을 저장하고 입력을 비웁니다. 이름 중간의 공백은 유지합니다.
- 왼쪽은 성공했을 때만 `form.reset()`을 호출합니다. 오른쪽은 Action 반환값의 `input`을 `defaultValue`에 전달해 React의 자동 초기화 이후 입력을 복원합니다.
- 코드 화면을 오가면 폼이 제거되어 입력과 제출 기록이 초기화됩니다.

양쪽에 `  김  `을 입력하면 길이 오류 후 원문이 남습니다. `  김 실험  `을 실패 모드로 제출해도 원문이 남고, 실패 모드를 끄면 `김 실험`으로 저장되며 입력이 비워집니다. 성공한 뒤 다시 실패해도 마지막 저장 이름은 유지됩니다.

코드 비교에는 각 폼과 공통 `form-action.ts`를 함께 표시합니다. `초기화와 입력 복원 정책` 토픽에서 UI 초기화 방식과 원문·정규화 이름을 나누는 처리를 확인할 수 있습니다.

회귀 확인: `node --test scripts/form-actions.test.mjs`
