# 낙관적 업데이트와 실패 복구

- 원본: `/front-feature/react/optimistic`
- 디자인 데모: `#/features/react/optimistic`
- 비교: 수동 상태 복제·롤백 / React `useOptimistic`

두 구현에 같은 요청 ID와 실패 조건을 전달합니다. 항목은 즉시 표시하며, 2초의 로컬 지연 뒤 성공한 항목을 부모의 확정 목록에 반영합니다. 실패 조건을 켜고 3개를 추가하면 첫 요청은 실패하고 나머지 두 요청은 성공합니다. 서버에 저장하지 않으며 처리 속도를 측정하지 않습니다.

부모는 요청을 개별 항목으로 보관하고, 양쪽의 처리 ID를 따로 기억합니다. 코드 화면에서 만든 요청도 사라지지 않으며 UI로 돌아올 때 아직 처리하지 않은 요청을 순서대로 한 번씩 시작합니다. 처리 중 코드 화면으로 이동해도 이미 시작한 성공 결과는 확정 목록에 남습니다. 이 요청 관리는 `useOptimistic` 자체의 기능이 아닙니다.

수동 구현은 로컬 목록과 이전 상태를 직접 유지합니다. `useOptimistic` 구현은 원본 목록에 낙관적인 변경을 적용하고 Transition의 완료에 따라 낙관 상태를 정리합니다. 코드 화면은 실제 두 데모 파일을 읽어 표시하며, 마우스 하이라이트와 키보드로 펼칠 수 있는 코드 해설을 함께 제공합니다.
