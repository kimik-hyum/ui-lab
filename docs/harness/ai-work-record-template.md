# AI 작업 품질 기록

AI가 프레임워크별 구현·수정 과제를 얼마나 잘 수행하는지 비교할 때만 사용합니다.
DX 코드 구조 점수, 브라우저 성능, SSR 측정과 별도로 기록합니다.

## 비교 조건
- 같은 시작 코드·과제·수락 조건을 사용하고, 실행마다 변경 전 상태에서 새 세션으로 시작합니다.
- 모델과 도구 버전, 제공 지침·스킬·도구·권한, 시간·토큰 한도를 기록합니다. 조건이 다르면 별도 결과로 표시합니다.
- 성공은 사전에 정한 테스트와 사용자 동작으로 판정합니다. 자기평가만으로 성공을 확정하지 않습니다.
- 한 번의 성공으로 순위를 정하지 않습니다. 반복 횟수와 실패 사례를 함께 남깁니다.
- 확인할 수 없는 시간·토큰은 추정하지 않고 `미수집`으로 표시합니다.

## 실행 기록 양식

```md
# AI 작업: {scenario-id} / {run-id}

- 대상 프레임워크:
- 시작 코드: {commit 또는 작업 스냅샷 식별자}
- 과제·동일 프롬프트:
- 수락 조건:
- 모델 ID / 실행 도구·버전:
- 지침·스킬: {사용 경로와 revision}
- 사용 가능한 도구·권한 / 실행 한도:
- 결과: {성공 / 실패 / 중단}
- 재수정 횟수: {첫 결과 검증 후 다시 고친 횟수}
- 사람 개입: {횟수와 핵심 내용}
- 소요 시간 / 입력·출력 토큰:
- 판정 근거: {검사 결과·실제 동작}
- 실패 원인 또는 비교 조건의 차이:
```

여러 실행을 비교할 때 성공 수/전체 수, 재수정·개입 횟수, 시간·토큰을 각각 표시합니다.
