# UI-LAB 기획·디자인 검토

$ARGUMENTS

루트와 `apps/lab-shell/AGENTS.md`를 참고해 요청을 검토합니다.

- 무엇을 비교하고 사용자가 어떤 차이를 직접 확인할지 정합니다.
- 해당 카테고리와 하위 페이지, 최소 데모와 조작, 코드 설명의 배치를 제안합니다.
- 기존 화면·디자인 토큰·설치된 컴포넌트에서 재사용할 것을 확인합니다.
- 핵심 판단, 필요한 변경, 남은 쟁점을 짧게 정리합니다.

검토만 요청했다면 제안으로 마칩니다. 구현까지 요청받았다면 확정된 범위에서 진행합니다. 별도 페르소나 대화나 반복 승인 질문을 만들지 않습니다.
