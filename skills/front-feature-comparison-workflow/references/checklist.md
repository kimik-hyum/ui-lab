# 기능 비교 확인 항목

- 카탈로그의 상태·도입 버전·링크가 실제 페이지와 일치합니다.
- 좌우 데모가 동일한 입력에서 의도한 차이를 보여줍니다.
- 표시 코드는 실제 실행 소스와 일치하고, 토픽은 차이와 영향을 짧게 설명합니다.
- 실행/코드 보기를 전환할 수 있고 해당 보기와 무관한 조작은 노출하지 않습니다.
- hover 토픽, 삭제·추가 또는 대응 줄 강조, 양쪽 스크롤 매칭이 자연스럽습니다. 마커 누락 fallback도 유지합니다.
- 모바일에서 코드·내용이 잘리거나 전체 페이지에 불필요한 가로 넘침이 생기지 않습니다.
- 공통 화면의 상세 경로와 직접 진입·목록 복귀가 같은 카테고리 안에서 동작합니다.
- 관련 회귀 테스트와 루트 `yarn check`를 통과합니다.
